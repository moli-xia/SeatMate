# SeatMate 会议排座工作台

一个无需后端、无需安装依赖的会议桌椅布局与排座工具。用木质明黄色工作台绘制会场，把会议名单整段粘进来自动分出姓名和单位，再按姓名或单位排座，最后导出图片或可继续编辑的布局文件。


![SeatMate 排座示例](docs/layout-example.png)

上图由应用实际导出（`导出图片`），名单与会议名称均为演示内容。座位上大多写姓名，其中一席写的是单位名称「市港务发展集团有限公司」——两种都能一键排上。

## 界面

打开后是左中右三栏：

- **左栏「布局与素材」**：十个绘制工具（选择、平移、桌面、矩形、圆角、圆形、三角、椅子、椅子排、文字）、色板卡（图形填充 / 文字颜色、10 个预设色与自定义色）、快速布局模板和草稿参考。
- **中间「会场画布」**：1600 × 1000 的会场。顶部一条工具条（全选、撤销 / 重做、组合、复制、删除、属性），底部是缩放与适配。
- **右栏**在「人员名单」和「对象属性」之间切换。名单栏顶部是排座概览，中间是**姓名 / 单位两列**的名单，每条右侧有座位号、「改」和「×」；属性栏按选中对象类型显示可改的字段。

窄屏（约 800px 以下）自动切换为「布局工具 / 会场画布 / 名单属性」三个标签页，撤销 / 重做移到画布下方。


## 本地运行

直接用浏览器打开 `index.html`，或在项目目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765 。数据保存在当前浏览器、当前站点的本地存储中；更换浏览器、地址或端口时，请用 JSON 布局文件迁移。改名前（Tableset）保存的布局会自动读取一次并转存到新的存储键。

## 绘制和编辑

- 左侧提供选择、平移、桌面、矩形、圆角矩形、圆形 / 椭圆、三角形、椅子、椅子排和文字十个工具。每画完一个对象，自动回到“选择”，可以立即拖动布局。
- “选择”本身就能拖出选框批量选中，旋转由控制点、方向键和工具栏按钮完成，因此不再单列“框选”和“旋转”工具。
- “椅子排”拖出一条线，沿线放置等距、同朝向的一排椅子，拖动时画布底部显示将要放置的数量；松开后整排自动选中，靠近桌子的还会贴合桌边。
- 选中对象后，四个角点调整宽高，四条边的中点分别拉宽或拉高；旋转后的对象也支持沿自身方向拉伸。
- 文字外框始终包住文字。拖角点时文字随边框一起放大或缩小，没有上限；拖边中点只改变框体，文字重新换行。属性面板可以直接设定字号和字体（默认雅黑、黑体、宋体、楷体），字号调大时文字框自动加宽加高来容纳，不会被压回原来的大小。
- 色板卡包含 10 个预设色和自定义颜色。“图形填充”和“文字颜色”分别修改选中对象的底色及文字，也支持批量改色。没有选中对象时，设置下一次绘制的颜色。
- 方向键设置选中对象的绝对朝向：`↑` 0°、`→` 90°、`↓` 180°、`←` 270°。工具栏旋转按钮及 `[` / `]` 每次旋转 90°，旋转控制点还支持自由角度。
- 桌面附近的座椅会自动贴合桌边、面向桌子并留出间距；移动、旋转或缩放桌子时，附着的座椅一起跟随。拖远、按住 Alt 拖动，或关闭“座椅自动贴合桌边”，可以自由摆放。手动拉伸、设置坐标或旋转单独座椅时会解除附着。
- 矩形、圆角及圆形的属性面板可勾选“作为桌面，允许座椅贴合”，用于自定义桌子。圆桌模板已启用此设置。
- “快速布局”提供围桌会议（16 座）、课堂培训（24 座）、圆桌交流（24 座）三个可编辑模板。套用模板保留名单，并重新安排座位。
- 页顶提供带文字的“上一步 / 下一步”按钮；手机端位于画布下方。替换模板、清空布局和导入后也可以撤销；刷新页面后撤销历史重新开始。

## 人员和单位名单

姓名与单位名称均可直接作为一个参会条目，例如：

```text
张三、李四；华景科技有限公司
市文化和旅游发展服务中心，王五 | 市财政局
```

支持换行、顿号、中英文逗号及分号、竖线、斜线、制表符、普通和全角空格。含空格或逗号的名称可用英文双引号包住，例如 `"North Star, Inc."`。同名同单位自动合并；同名但不同单位会保留为不同条目。

单位名称按关键字自动识别，中文含“公司、集团、大学、中心、委员会”等词或以“局、厅、处、院”等字结尾；英文含 `Inc.`、`Ltd`、`LLC`、`Corp.`、`GmbH`、`Company`、`University`、`Institute`、`Foundation` 等词。其余条目按人名处理，名单卡片上分别显示“单位”和姓名。

从会议通知里直接粘贴的一行，也能自动拆成姓名和单位。名单里常见的姓名会用空格撑开对齐，后面接单位和职务：

```text
黄  成  市水路建设养护发展中心港口科科长
李 建 国  市财政局办公室主任
王丽  市文化和旅游发展服务中心副主任
```

会被识别为：

| 姓名 | 单位 |
| --- | --- |
| 黄成 | 市水路建设养护发展中心 |
| 李建国 | 市财政局办公室 |
| 王丽 | 市文化和旅游发展服务中心 |

姓名取空格撑开的前几个字；单位取到第一个能结束单位名的词为止，后面的职务不会进入名单：

- 先找完整的词：中心、委员会、研究院、有限公司、集团、大学、医院 等。`集团` 后面的 `有限公司` 会一起带上，所以 `市港务发展集团有限公司战略发展部部长` 得到 `市港务发展集团有限公司`。
- 没有完整的词时才看单字：局、厅、办、委、院、部、处、科、室、站、所、厂、司、队。因此 `市工业和信息化局装备工业科科长` 在 `局` 处截断，而 `华景科技有限公司` 不会在 `科技` 的 `科` 处截断。
- 括号里的词属于附注：`市园区办（投资促进局）投资二科副科长` 得到 `市园区办`，不会被括号内的 `局` 带偏。
- 只有职务没有单位时（例如 `赵四  高级工程师`），单位留空而不是把职务当成单位。

整行是一个人时，行内的顿号属于职务而不是分隔符：`吴柏松  市交通运输局党组成员、副局长` 是一条记录（吴柏松 / 市交通运输局），不会被拆成两个人。`张三、李四、王五` 这类整行都是名字的仍然按顿号拆开。

`张三 李四 王五` 这类没有单位线索的一行仍然按空格拆成多个人。用英文双引号包住的条目按原样保留，不再拆分也不提取单位。

也支持导入 TXT / CSV，包括仅有单位的名单，以及带表头的姓名、单位数据：

```csv
姓名,单位
张三,设计部
李四,财务部
,市财政局
```

没有姓名的行会使用单位作为参会名称。仅有 `单位名称` 表头的文件也可直接导入。

名单按“姓名”和“单位”两列显示，左侧色条按单位分组。每条右侧的“改”可以分别修改姓名和单位，“×”移除该条；修改会写入撤销历史，也会重新给座位上的名字留出空间。

**两列都能排座，点哪列座位就写哪列。** 点“姓名”座位显示姓名，点“单位”座位显示单位名称；拖动同理，拖动时的浮标就是将要写上去的文字。没有单独单位的条目（纯单位条目，或单位列显示“—”的）点哪边都用左侧名称。排好后还可以在座位属性面板的“座位显示”里在姓名和单位之间切换，座位大小会跟着重新计算。

将名单卡片拖到座位上即可安排；也可先选中座位，再点击名单卡片，或使用“一键自动排座”（默认用姓名）。搜索和排座状态筛选帮助查找条目。普通短姓名尽量保持一行，长单位完整换行，文字保持正向并按座椅空间缩放。

中文按字换行，英文只在空格处断开，`Nordic Consulting` 会排成“Nordic / Consulting”而不会拆散单词。安排姓名时座椅自动增大到名字清晰可读；旋转座椅或旋转整张桌子后会重新计算，转回原方向时座椅恢复原尺寸。手动拉伸或在属性面板改宽高后，以你设定的尺寸为准。名称特别长或会场很密集时，可继续用拉伸点、字号属性和画布缩放调整。

## 保存、导入和导出

- 编辑后自动保存，可通过顶部状态查看是否成功；`保存` 按钮和 `Ctrl+S` 可立即保存。
- `布局文件 → 导出布局` 生成 JSON，保留对象、颜色、旋转、文字框、名单、座位分配（含每个座位显示姓名还是单位）、桌椅关联、视图及草稿数据。
- `布局文件 → 导入布局` 恢复项目；校验失败不会覆盖当前工作。兼容旧版布局，升级旧文字框和默认配色。
- `导出图片` 生成 3200 × 2000 的 PNG，保留画布中的颜色和文字排版，移除编辑控制点。导出范围为 1600 × 1000 的会场，请把需要导出的对象放在此范围内。
- 原有草稿导入、参考图、放大查看和自动识别功能继续保留。识别结果是可编辑初稿，可手动校正。

## 开发与验证

原生 HTML、CSS、JavaScript，无构建步骤。`app.js` 负责界面及交互，`editor-core.js` 提供名单解析与姓名 / 单位提取、文字排版、旋转拉伸及桌椅吸附几何，`project-format.js` 校验布局文件。

安装 Node.js 后运行回归检查：

```powershell
node --check app.js
node --test tests/editor-core.test.cjs tests/project-format.test.cjs
```

共 26 项检查，本轮全部通过。

实际浏览器验证记录见 [docs/validation.md](docs/validation.md)。推荐使用支持 SVG、Canvas、Pointer Events、ResizeObserver 和 HTML dialog 的现代浏览器。
